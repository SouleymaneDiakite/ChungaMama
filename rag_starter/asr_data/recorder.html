How to use
  1. Open this page from http://localhost (run python -m http.server 8000 in this folder, then open localhost:8000/recorder.html) in Chrome or Edge.
  2. Click Choose save folder and pick an empty folder (e.g. recordings). Clips are saved there as sw_001.wav + sw_001.txt. Come back any time: finished clips are detected from that folder.
  3. Press Record, wait a beat, read the text naturally, press Stop, then Play to check it. Save if it's clean; re-record if you stumbled.
  4. The transcript must match what you actually said. If you changed a word, edit the text box before saving (it turns orange and the edited text is what gets saved).
  5. Read numbers the way you'd say them (miezi 3 = "miezi mitatu", "3 months" = "three months"). Keep each clip under 30 s.
  6. Same mic, same distance, quiet room. Short sessions (25-30 clips) with breaks keep your voice and pace steady.
